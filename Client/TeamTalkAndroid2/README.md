# TeamTalk 5 client application for Android

This is the work in progress move of [TeamTalkAndroid](../TeamTalkAndroid) to
Kotlin and Jetpack Compose. See [discussion #3565](https://github.com/BearWare/TeamTalk5/discussions/3565).
The translations are read from TeamTalkAndroid until this client replaces it.

Use [Android Studio](https://developer.android.com/studio) to build
and run TeamTalk for Android.

To try this application go to [Google Play](https://play.google.com/store/apps/details?id=dk.bearware.gui).
